# HydroGuard submission summary

HydroGuard audits disclosed EIA claims and prepares defensible consultation
questions. Submission scope is a working input-dependent offline audit plus
verified live Zetaris passage retrieval, **not** the complete sponsor architecture.

## What judges can run

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
SAMPLE_MODE=true python run.py
# In another terminal:
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/run -H 'Content-Type: application/json' --data-binary @input_examples/water.json
# With the environment activated:
python -m pytest -q
```

Use `land.json` and `air.json` for the other scenarios. All three output examples
were generated by `SAMPLE_MODE=true python -m scripts.generate_examples`; runtime
code never replays them. Offline rules and synthetic records are clearly labeled.
